# 双体角色（TwinBody）控制文档

本文档面向策划/关卡设计，说明当前双体角色（珍妮佛 + 约翰）的生成方式、可调参数、以及如何替换贴图。角色相关脚本位于 `Assets/Scripts/Character/`，一键生成工具位于 `Assets/Scripts/Editor/TwinBodyCharacterPrefabBuilder.cs`，最终产物是 `Assets/Prefabs/Character/TwinBodyCharacter.prefab`，已经挂在 `ShootingGameMain` 场景的 `LevelManager.PlayerPrefabs` 上，直接 Play 即可用。

---

## 1. 角色是什么

角色由三部分组成，**共用同一个 `Rigidbody2D`**（复合碰撞体），因此整体始终保持刚性结构、可以自由旋转，不会像 Corgi 默认角色那样被强制拉直贴地：

| 节点 | 对应设定 | 碰撞体 | 功能 |
|---|---|---|---|
| `Jennifer` | 珍妮佛 | `CircleCollider2D` | 舌头（右键） |
| `John` | 约翰 | `CircleCollider2D` | 枪（左键，武器挂点） |
| `ConnectorBody` | 中间连接件 | `BoxCollider2D` | 纯物理连接，无功能 |

根节点上还挂了 Corgi 的 `Character` 组件和一个**永久禁用**的 `CorgiController`——这两者只是为了满足 `LevelManager.PlayerPrefabs`（类型是 `Character[]`）的挂载要求，以及让 `Character.Update()` 帮忙驱动 Ability 生命周期，**不参与实际物理/移动**，改它们没有意义。

---

## 2. 如何生成角色

### 2.1 一键重新生成（会覆盖 `TwinBodyCharacter.prefab`）

菜单：**`Tools → Character → Build TwinBody Character Prefab`**

这会从零搭建一个新的角色 GameObject：两个圆形节点 + 一个方形连接件、挂好 `Rigidbody2D`、`Character`、禁用的 `CorgiController`、`TwinBodyCharacter`、`CharacterHandleWeapon`（自动从 `Assets/Prefabs/GunTemp.prefab` 取武器）、`TwinBodyGun`、`TwinBodyTongue`，然后另存为 `Assets/Prefabs/Character/TwinBodyCharacter.prefab`。

**什么时候用这个菜单：**
- 角色结构被改乱了，想恢复到脚本定义的初始结构；
- 改了 `TwinBodyCharacterPrefabBuilder.cs` 的搭建逻辑（比如加新节点、换武器路径），需要重新出一版 prefab。

**注意：**
- 会直接覆盖现有 prefab 文件，之前在 Inspector 里手调的参数（半径、间距、移速……）会被重置为脚本里的默认值，重新生成前记得先记录/备份想保留的数值。
- 如果找不到 `Assets/Prefabs/GunTemp.prefab` 或其 `Weapon` 组件，Console 会警告，此时需要在生成后手动把武器拖进 `CharacterHandleWeapon.Initial Weapon`。

### 2.2 日常调参（推荐）

不需要重新生成，直接在 Project 里选中 `Assets/Prefabs/Character/TwinBodyCharacter.prefab` 进入 Prefab 编辑模式（双击），或者在场景里选中运行时的角色实例，在 Inspector 上改 `TwinBodyCharacter` / `TwinBodyGun` / `TwinBodyTongue` 组件的字段即可，**改动即时生效**：
- 物理参数（重力、质量、阻尼）改了会自动同步到 `Rigidbody2D`；
- 节点半径/间距/连接件厚度改了会自动重新摆放两个节点和连接件；
- 都不需要重新点生成菜单，也不需要进 Play 模式。

这是因为 `TwinBodyCharacter.OnValidate()` 每次改字段都会调用 `SyncPhysics()` + `ApplyLayout()`。

## 3. 参数说明

### 3.1 `TwinBodyCharacter`（整体骨架 / 基础移动，根节点）

**刚体物理**（自动同步到 `Rigidbody2D`）

| 参数 | 说明 |
|---|---|
| Gravity Scale | 重力倍率 |
| Mass | 整体质量，影响后坐力/牵引力打上去的实际加速度 |
| Linear Damping | 线性阻尼，越大移动/冲击后越快停下来 |
| Angular Damping | 角阻尼，越大旋转后越快停止转动 |

**节点位置 / 大小**（改动自动应用，无需重跑生成菜单）

| 参数 | 说明 |
|---|---|
| Node Radius | 珍妮佛 / 约翰两个节点的半径（世界单位） |
| Node Distance | 两节点中心间距，可以为 0（贴在一起） |
| Connector Thickness | 中间连接件（矩形）的厚度 |

**基础横向移动 A/D**

| 参数 | 说明 |
|---|---|
| Read Input | 是否读取键盘输入（关掉后角色不响应 A/D，比如做过场动画时用） |
| Move Speed | 水平移动的目标速度上限 |
| Move Acceleration | 加速度，越大越快达到目标速度、越"跟手" |

> 目前移动固定读键盘 A/D，不走 Corgi 的 `InputManager`，因为该原型角色没有走标准的 `CorgiController` 输入分支。

### 3.2 `TwinBodyGun`（约翰的枪，挂在根节点）

开火/瞄准/弹道/伤害全部由 Corgi 官方的 `CharacterHandleWeapon` + `GunTemp.prefab`（`ProjectileWeapon`）负责，左键朝鼠标开火。`TwinBodyGun` 只补两件事：

| 参数 | 说明 |
|---|---|
| Ammo Regen Interval | 不开枪时，每隔多少秒自动回复 1 发弹匣（叠加在官方弹匣之上） |
| Recoil Force | 每次开火施加到 `JohnNode` 刚体上的后坐力大小 |

> 官方后坐力（`GunTemp` 上 `ProjectileWeapon.RecoilOnUseProperties`）对这个角色是**无效**的，因为它依赖 `CorgiController`，而这个角色永久禁用了它。真正生效的后坐力只有 `TwinBodyGun.Recoil Force` 这一个参数。

**武器本身的参数**（在 `Assets/Prefabs/GunTemp.prefab` 上，`ProjectileWeapon` 组件）：

| 参数 | 说明 |
|---|---|
| Time Between Uses | 两次开火的最小间隔（射速） |
| Magazine Size | 弹匣容量（当前 20） |
| Ammo Consumed Per Shot | 每次开火消耗弹药数 |
| Reload Time / Auto Reload | 换弹耗时 / 打空是否自动换弹（当前手动换弹） |
| Projectile Spawn Offset | 子弹生成点相对武器的偏移 |
| Projectiles Per Shot / Spread | 单次开火的弹丸数 / 散射角度（当前单发无散射） |
| Weapon Attachment Offset | 武器相对挂点（John 节点）的偏移 |

伤害数值挂在子弹本身（`MachineGunShells` 子物体）的 `DamageOnTouch` 一类组件上，如需要调伤害/命中效果，进 `GunTemp.prefab` 里的子弹物体调整（当前是原型武器，还没有配置伤害值，需要接实际战斗前记得补上）。

### 3.3 `TwinBodyTongue`（珍妮佛的舌头，挂在根节点）

右键**点一下**（不需要按住）朝鼠标方向发射一条射线：

| 参数 | 说明 |
|---|---|
| Read Input | 是否响应右键输入 |
| Tongue Length | 舌头射线最大长度 |
| Hit Mask | 舌头能打中的层，默认排除角色自身所在层 |
| Reel Speed | 卷线速度，即目标被拉向嘴巴的速度 |
| Eat Distance | 目标离嘴巴（珍妮佛节点）多近算被吃掉 |
| Ammo Restore On Eat | 吃掉一个可捕获物回复约翰弹匣的发数 |
| Pull Impulse | 打中"不可食用"的普通碰撞体（地形、墙壁等）时，给整体刚体的一次性牵引冲量大小 |

**行为分支：**
- 打中挂了 `TongueCapturable` 组件的物体 → 拉过来吃掉，回复弹匣，物体被 `Destroy`；
- 打中任何其他实体碰撞体（地形、墙壁……）→ 朝命中点给一次性冲量，牵引一下，无持续效果，松不松右键无所谓。

**关卡侧配置：**
- 想让某个物体能被舌头吃掉 → 给它挂 `TongueCapturable`（`Assets/Scripts/Character/TongueCapturable.cs`）。
- `TonguePullAnchor`（同目录）目前是预留的摆荡锚点标记组件，尚未接入任何逻辑。

## 4. 贴图 / 外观

当前角色用的是 **Unity 内置占位贴图**（`Sprites/Circle.psd` / `Sprites/Square.psd`），靠颜色区分身份，还没有正式立绘：

| 节点 | 内置贴图 | 颜色 |
|---|---|---|
| Jennifer | Circle | 粉色 `(1, 0.35, 0.6)` |
| John | Circle | 蓝色 `(0.3, 0.55, 1)` |
| ConnectorBody | Square | 灰色 `(0.75, 0.75, 0.75)` |

### 4.1 替换节点贴图

1. 打开 `TwinBodyCharacter.prefab`（双击进入 Prefab 编辑模式）；
2. 分别选中子物体 `Jennifer` / `John` / `ConnectorBody`；
3. 在其 `Sprite Renderer` 组件上，把 `Sprite` 字段换成美术资源即可；颜色（`Color` 字段）建议改回白色 `(1,1,1,1)`，避免和贴图本身颜色叠加变色。
4. 贴图的显示大小由 `TwinBodyCharacter` 组件的 `Node Radius` / `Connector Thickness`（通过 `localScale`）控制，**不需要**去改 `Sprite Renderer` 或 `Transform.Scale`——那些会被 `ApplyLayout()` 在下次校验时覆盖掉。
5. 如果换成非正方形素材（比如角色立绘），碰撞体（`CircleCollider2D`/`BoxCollider2D`）不会自动跟贴图形状匹配，需要单独调碰撞体的 `Offset`/`Radius`/`Size`，或者把贴图渲染额外挂一个子物体（不缩放碰撞体所在节点），避免物理判定和美术表现脱节。

### 4.2 替换武器贴图

进入 `Assets/Prefabs/GunTemp.prefab`，找到武器可视化子物体（`MachineGun`）上的 `Sprite Renderer`，替换其 `Sprite` 字段。枪口特效（`MachineGunFlames`）、弹壳/子弹（`MachineGunShells`）也各自有独立的 `Sprite Renderer`，可以分别替换。

### 4.3 关于动画

目前角色没有 `Animator`，都是纯 Sprite + 物理表现（旋转由刚体真实旋转驱动，不是动画）。如果后续要接入骨骼动画或帧动画，需要新增 `Animator` 组件并评估是否与当前"自由旋转刚体"的物理方案冲突（比如动画驱动的 Transform 和刚体旋转互相打架），建议先和程序确认方案再动手。

## 5. 常见问题

**Q: 改了 Inspector 里的参数，Play 之后又变回默认值了？**
A: 检查是不是在场景里改了运行时实例而不是 prefab 本身——运行时实例的改动不会保存；应该在 Project 窗口双击 prefab 进入编辑模式修改，或者退出 Play 模式后用 Inspector 右上角 "Overrides → Apply All" 把场景实例的改动写回 prefab。

**Q: 点了生成菜单，武器没了 / Console 报警告找不到 GunTemp？**
A: 确认 `Assets/Prefabs/GunTemp.prefab` 存在且没有被移动路径；`TwinBodyCharacterPrefabBuilder.cs` 里 `JohnGunWeaponPath` 常量写死了这个路径，挪动了武器 prefab 需要同步改这个常量，或者生成后手动把武器拖进 `CharacterHandleWeapon.Initial Weapon`。

**Q: 后坐力 / 舌头牵引调了但是没反应？**
A: 确认力是打在正确的节点上（后坐力打 `JohnNode`，舌头牵引打 `JenniferNode`），以及 `Mass` 是否过大——`Mass` 越大，同样的 `Impulse` 造成的速度变化越小。
